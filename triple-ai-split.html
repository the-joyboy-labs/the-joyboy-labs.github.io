// FEATURES IN THE README

Compare, debate, and resume

A concise overview of the features described for version 1.3.1; behavior depends on the target sites' current UI.

01 / AUTO TILING

Three windows, side by side

Measures the screen and arranges Claude, Gemini, and ChatGPT left to right at roughly one third of the display each.

02 / ONE PROMPT

Choose who receives it

Type once, select the assistant panes, then send through each site's logged-in UI. Replies appear in the popup with copy controls.

03 / DEBATE MODE

Round-by-round exchange

Run 1–6 rounds: opening statements, responses to the other two assistants, then final conclusions.

04 / RETRY + STATE

Resume a paused debate

Retry a failed assistant at the same step; popup closure does not discard session progress, according to the README.

// REQUIREMENTS

Before you install

The extension automates consumer chat websites, so provider terms and browser behavior matter as much as the local extension version.

Environment listed by the README

  • Windows 10 or 11 for the tuned window tiling.
  • Google Chrome 111 or newer, or Microsoft Edge.
  • Signed in to Claude, Gemini, and ChatGPT in the same browser.
  • Extracted extension folder kept in a permanent location after loading it unpacked.

Privacy and site behavior

The extension has no server according to the README, but the prompt is sent to the selected provider websites using your session. Each provider's own policies apply.

Automation may conflict with those websites' terms. The page-detection selectors can break when a site changes; use at a normal pace and avoid sensitive prompts.

// INSTALLATION

Load the unpacked extension

This is a summary of the README's manual install flow. The supplied project repository is the source for the current files.

  1. Get the files: use the repository's Code → Download ZIP option, extract it, and keep the folder somewhere permanent.
  2. Open the extensions page: visit chrome://extensions in Chrome or edge://extensions in Edge.
  3. Enable Developer mode in the browser's extensions manager.
  4. Load unpacked: choose the extracted folder that contains manifest.json.
  5. Pin the extension from the toolbar's extensions menu.
  6. Sign in first to the AI sites you intend to use in the same browser profile.
  7. Open the three windows, then use the popup to send a prompt or start a debate.

// USING THE EXTENSION

Normal chat and debate

The extension interacts with the providers' website interfaces; it is not described as using official model APIs.

Normal chat

  1. Open the three windows and wait for the sites to load.
  2. Enter a prompt in the popup and choose which columns to include.
  3. Use Send to all or Ctrl + Enter.
  4. Watch the Sending → Waiting → Replying → Done states.
  5. Copy a reply or start fresh chats.

Debate

  1. Choose Debate, enter a topic, and set 1–6 rounds.
  2. Each assistant receives the other two assistants' latest replies.
  3. The sequence ends with a final conclusion from each assistant.
  4. If one page fails, the debate pauses; retry that assistant at the same step.
  5. Use Copy full debate to copy the transcript; Close clears the debate.

// IMPLEMENTATION NOTES

Reliability decisions

The README focuses on changing consumer-site interfaces and background-window behavior.

Typing and sending

The README says rich-text editors are handled with document.execCommand('insertText') and a simulated-paste fallback, rather than assigning .value or .textContent. It clicks an enabled send button and uses Enter as a fallback.

Fresh selectors and reply completion

Elements are looked up again rather than keeping stale references. A reply is considered finished when real text exists, the stop button is gone, and text is stable for a few seconds (3 seconds normally, 6 in debate); it continues watching afterward in case more text arrives.

Finding a new reply

A reply counts as new if the reply-box count increases or the latest reply begins differently from the previous one. This handles sites that remove or rebuild prior message nodes.

Popup state and concurrent writes

The README stores replies and debate progress in chrome.storage.session and the draft prompt in chrome.storage.local. Result writes are serialized to prevent a late status note from overwriting a reply.

What the README says changed

// TROUBLESHOOTING

Quick checks

Selectors and site behavior can change. These suggestions summarize the README and do not guarantee compatibility.

Could not reach a page / prompt took too long to send

Wait for the provider site to load, confirm you are signed in to the intended account, and open the three windows again if needed.

Message box or send button not found

A site may have changed its UI or a popup may cover the editor. The README points to the selectors in config.js; update only against the current site and use within its rules.

Sent, but no reply appeared

Check whether generation is active, whether the window is hidden/covered, and whether the reply selector detects new text. Site UI changes may require selector maintenance.

Lost contact or debate paused

The page may have reloaded or closed. In debate mode, the README says to fix the underlying issue and use Retry to continue from the same step.

Windows do not line up / keep coming to the front

The README describes a Windows frame-size adjustment and a checkbox to disable optional auto-bring-to-front. Consider leaving foreground automation off if it disrupts normal browsing.

Stop does not stop a provider that is already generating

The README lists this as a known limitation; stop generation from that provider's own window.

Extension disappeared after moving its folder

Chrome/Edge loads the unpacked extension from its folder. Load it again from the new permanent location.

// LIMITS & HONEST NOTES

A UI automation, not an official integration

The extension is independent and is not affiliated with Anthropic, Google, or OpenAI.

Use personal data thoughtfully

Selectors are best guesses and can stop working when sites change. The README says the extension has no server, but your prompt and the resulting interaction still go to the selected AI providers. Consumer-site automation may violate their terms; use at a normal pace, avoid confidential prompts, and review both the extension manifest and each provider's privacy terms. The “always awake” page behavior and auto-bring-to-front can affect normal browser behavior.
