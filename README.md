# The Joyboy Labs

A responsive, dark-mode portfolio and resource site for Roblox Luau scripts, Python automation tools, and responsible cybersecurity learning.

## Structure

- `index.html` — landing page
- `roblox.html` — Roblox Studio / Luau examples
- `python.html` — Python automation example
- `cyber.html` — defensive security example and learning links
- `css/style.css` — shared responsive styles and theme variables
- `js/main.js` — mobile navigation, copy-to-clipboard buttons, and footer year
- `assets/` — reserved for your logo and images

## Download bundle

The complete static site is also packaged separately at [`downloads/the-joyboy-labs-site.zip`](downloads/the-joyboy-labs-site.zip).

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server. There is no build step, framework, backend, or database.

## Publish with GitHub Pages

In the repository's GitHub settings, enable Pages and publish the repository root from your chosen branch. Keep the relative links and folder structure as-is.

## Personalize

- Update the Discord link in each HTML page. It currently uses `https://discord.gg/joyboyhakari_16266`; replace that value with your actual server invite if `joyboyhakari_16266` is a username rather than an invite code.
- Add your pictures to `assets/` and reference them with relative paths.
- Adjust the color variables at the top of `css/style.css` if you want to tune the neon accents. The site is intentionally dark-only.
