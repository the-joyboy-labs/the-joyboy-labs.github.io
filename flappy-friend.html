// HOW TO PLAY

Pick. Tap. Dodge.

The Android game is the main project; these steps describe the local web preview shown above.

Choose an image

Use “Choose photo” to select a local picture. The browser demo does not upload it.

Start the run

Press Start / flap or tap the canvas. Each tap, click, Space, or Arrow Up gives a lift.

Dodge and compare

Pass the obstacle gaps, watch your score, then reset and pass the challenge to a friend.
