// DEFENSIVE MINI TOOL

Verify a file's SHA-256

A local integrity check helps confirm a downloaded file matches a hash published by a trusted source. It does not prove that the source itself is trustworthy.

TOOL 01 / FILE INTEGRITY

Compare a local file to its published hash

Replace the filename and expected digest with values from the software publisher's official site.

PYTHON
verify_sha256.py
from hashlib import sha256
from pathlib import Path

EXPECTED_SHA256 = "replace-with-the-published-sha256"

def sha256_file(file_path: Path) -> str:
    digest = sha256()
    with file_path.open("rb") as stream:
        for chunk in iter(
            lambda: stream.read(1024 * 1024), b""
        ):
            digest.update(chunk)
    return digest.hexdigest()

def verify_file(file_path: Path, expected: str) -> None:
    actual = sha256_file(file_path)
    matches = actual == expected.strip().lower()
    print(f"SHA-256: {actual}")
    print("MATCH" if matches else "MISMATCH")

if __name__ == "__main__":
    verify_file(Path("download.zip"), EXPECTED_SHA256)

Use a complete SHA-256 digest copied from the publisher. A matching hash confirms the file matches that value; verify the publisher and download channel separately.
